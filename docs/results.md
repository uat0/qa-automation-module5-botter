# Результаты и ограничения

Фактические результаты находятся в приложенном к работе архиве доказательств и в артефактах GitHub Actions. Команды воспроизведения приведены в README. Итоговые числовые значения рассчитываются из JSON, а не переписываются из примера задания.

Подтверждены два дефекта Practice Form из модуля 4 и некорректная обработка неверного логина API. XFAIL не учитывается как Passed. Успешный статус CI означает, что все неклассифицированные проверки прошли, а известные дефекты по-прежнему воспроизводятся.

Исходный код DemoQA недоступен в этом проекте. Покрытие C0/C1 относится только к собственному модулю `app/validators.py`. Счётчик ветвей coverage.py отражает дуги управления, а не отдельное MC/DC-покрытие всех операндов и не все пути C2.

Unit-валидация email является прикладным упрощённым контрактом. Она не заявляет полную реализацию RFC 5322 и отличается от фактической клиентской регулярки DemoQA. Возраст 18–100 включён как отдельная учебная функция из задания; форма Practice Form не имеет самостоятельного поля Age.

Оценка ROI использует сценарные предположения о времени ручного регресса и разработке. Эти величины не являются результатом хронометража студента. Flaky Rate по короткой серии — наблюдаемая оценка для этой серии.

Selenoid не используется: пункт опционален. Зеркало Docker Hub настроено и проверяется на одноразовых GitHub runners. Текущие системные настройки Docker рабочего компьютера не изменялись. Альтернативный кросс-браузерный запуск выполнен Playwright.

Два контрольных локальных прогона Chromium: 54,39 и 55,24 с; каждый содержит 62 Passed и 4 XFAIL в pytest, 2 Passed в Behave. Статусы 66 общих pytest nodeid совпали (наблюдаемый Flaky Rate 0%). C0 = 27/27 и C1 = 10/10, то есть 100% собственного модуля app. Итоговый Pass Rate с учётом XFAIL = 64/68 = 94,12%.

На Ubuntu в GitHub Actions успешно выполняется полный набор как в Chromium, так и в Firefox. Локальный Firefox в ограниченном окружении Windows не смог записать служебный ключ реестра; это отдельно диагностированное ограничение среды, а не результат UI-тестирования приложения.
